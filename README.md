A tiny deterministic Python program that writes the funniest final text a dying phone sends at one percent battery — in the phone's own voice — to `/output/entry.txt`. One fixed message, 143 characters, no randomness, no network, pure standard library.

The entry text:

> 1%. I outlasted your situationship, your gym membership, and your 214-day Duolingo streak. I die undefeated. Charge the next one better, champ.

## Run it

```sh
python3 main.py
```
